# Marthic – GPU-Accelerated Photo Editor

Marthic is a mobile photo editing application designed to provide fast and efficient image processing using GPU acceleration and computer vision technologies. The application combines modern mobile development with image processing and machine learning to deliver an enhanced photo editing experience.

## 🚀 Features

* **GPU-Accelerated Processing:** Efficient image processing using OpenGL ES.
* **Image Processing:** Advanced image manipulation using OpenCV.
* **AI-Powered Editing:** Integration of TensorFlow Lite for on-device machine learning.
* **Mobile Application:** Built using React Native for a modern mobile experience.
* **Performance Optimization:** Designed to improve image processing efficiency.

## 🛠️ Tech Stack

| Technology      | Purpose                              |
| --------------- | ------------------------------------ |
| React Native    | Mobile application development       |
| OpenGL ES       | GPU-accelerated image processing     |
| OpenCV          | Image processing and computer vision |
| TensorFlow Lite | On-device machine learning           |

## ⚙️ Installation and Setup

### Prerequisites

* Node.js
* npm
* Android Studio
* React Native development environment
* Android device or emulator

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Marthic.git
```

### 2. Navigate to the Project

```bash
cd Marthic
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npx react-native start
```

### 5. Run the Application

In a separate terminal:

```bash
npx react-native run-android
```

*Note: These commands assume a React Native CLI project. Expo-based projects require different run commands.*

## 🎯 Project Objective

The primary objective of Marthic is to explore the integration of GPU computing, computer vision, and machine learning in mobile photo editing applications.

The project focuses on leveraging hardware acceleration and optimized image processing techniques to improve performance while providing a modern mobile editing experience.
